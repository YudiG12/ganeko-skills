# ADR 002: Everything starts in beta

| Status | Date | Deciders |
|---|---|---|
| Accepted | 2026-11-23 | Yudi Ganeko |

## Context
The skills are used daily and still change every week, but they are worth sharing now.

## Decision
- **All skills live in `skills/beta/`** until they graduate.
- **Graduation:** used in 3+ different projects, 2 weeks without a big change, and nothing tied to the author (paths, accounts, brand).

## Alternatives considered
| Option | Why not |
|---|---|
| Publish only finished skills | Nothing would ship for months |
| A version number per skill | Overhead for two skills; the folder says it |

## Consequences
Names and files may move while in beta; the README says so up front.
